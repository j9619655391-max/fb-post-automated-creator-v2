# Quote Category Strategy — Love, Truth, Motivational, Pain

## Purpose

The quote workspace is a four-category editorial system, not a generic quote bucket. Each category must have a distinct emotional job, copy pattern, visual recommendation, and moderation boundary while sharing one recognizable brand identity. The platform should recommend categories from workspace evidence but allow the operator to override the recommendation before generation.

## Category operating model

| Category | Reader need | Emotional promise | Preferred visual families | Copy boundary |
|---|---|---|---|---|
| Love | Connection, affection, reassurance | “Your feelings and relationships can be expressed with warmth.” | Centered Gallery, Paper Note, Photo + Quote Panel | Avoid possessiveness, manipulation, stalking, or idealizing disrespect |
| Truth | Reflection, clarity, honesty | “A clear thought can help you see a situation differently.” | Editorial Split, Type Poster, Quiet Luxury | Avoid unverifiable universal claims and targeted accusations |
| Motivational | Agency, progress, courage | “One realistic next step is possible.” | Type Poster, Brush Frame, Editorial Split | Avoid shame, burnout glorification, guaranteed success, or diagnosis |
| Pain | Validation, healing-oriented hope | “Difficulty can be acknowledged without becoming identity.” | Paper Note, Photo + Quote Panel, Quiet Luxury | Avoid self-harm romanticization, diagnosis, or glamorizing suffering |

## Hinglish editorial rules

The workspace should write in natural Roman Hindi with simple English. A category may have an English label for navigation, but the quote and caption should sound like a bilingual social page rather than translated corporate copy. The system must keep second-person style consistent, avoid forced slang, use phrase-level line breaks, and run a spelling/grammar review before image rendering.

## Category routing

Category recommendation should use the workspace profile, page description, source evidence, and recent content history. A quote page with evidence such as `truth`, `reality`, `sach`, `love`, `pyaar`, `dard`, or `motivation` should receive quote categories before fashion/product categories. Recent category and template fatigue should influence ranking: a page that published several Truth cards should receive a different category or visual treatment rather than a duplicate idea.

## Content contract

Every category package contains a concise image quote, a separate caption reflection, one low-pressure CTA, relevant hashtags, verified tags only, and three platform variants. The image should not carry the entire caption. The category label, quote-length mode, selected template, and language mode must be shown in the pre-generation confirmation.

## Category quality checklist

| Check | Love | Truth | Motivation | Pain |
|---|---|---|---|---|
| Natural Hinglish | Required | Required | Required | Required |
| Specific emotional situation | Required | Required | Required | Required |
| No invented facts/contact | Required | Required | Required | Required |
| No coercive framing | Required | Required | Required | Required |
| No diagnosis or therapeutic promise | Required | Required | Required | Required |
| Branded image package | Required | Required | Required | Required |
| Human approval before publishing | Required | Required | Required | Required |

## Implementation mapping

The category catalog belongs in seed/bootstrap configuration and should be workspace-aware. VCE ranking maps evidence to categories; the generation service maps category to prompt rules and template defaults; the media composer maps the selected archetype to a platform layout; moderation validates category-specific risks; and the package service preserves caption, CTA, hashtags, and tags.
